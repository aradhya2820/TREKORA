TREKORA – A website for outdoor enthusiasts to browse and rent camping and hiking equipment.

- Purpose: Make quality camping gear affordable and accessible by allowing users to rent equipment instead of purchasing expensive products used occasionally.
- Tools: HTML, CSS, JavaScript, Git/GitHub.
- Implementation: Responsive frontend website with a camping gear catalog, category and temperature filters, rental packages, product details, a rental price calculator, a shopping cart, refundable deposit calculation, and a checkout and booking confirmation system.
- Project Type:Frontend-only (No Backend).
- Tagline: Explore More, Own Less.
- Live site:https://outdoorcamping.netlify.app
